# Berlin Imports

The Django application, local development setup, Tailwind build, and implementation status are documented in [berlin/README.md](./berlin/README.md). The product requirements are in [berlin_imports_project_requirements.md](./berlin_imports_project_requirements.md).

Start the application from the Django project directory:

```sh
cd berlin
```

Follow its README to install dependencies, configure `.env`, seed optional development products, apply migrations, run tests, and start Django.
